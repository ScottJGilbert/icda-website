# ICDA Website

The official open-source repository for the Illinois Congressional Debate Association (ICDA) website. This software runs on Apache HTTP Server with PHP, MySQL, and phpMyAdmin plugins.

## IMPORTANT!

Before making ANY updates to this website, be sure to make a full backup of both the website files and the associated MySQL database. The website can be backed up by simply zipping the entire filesystem and downloading it. Refer to the instructions on CPanel for backing up the MySQL database - but **BE SURE TO BACK IT UP TO A .SQL (SQLDUMP) FILE**.

If backing up the full site is not possible at least try to make backups of all non-static PDF documents on the site. This includes legislation, results, archive legislation/results, and the constitution. Any PDFs in the "Resources" section can be left alone.

This is to ensure that updates do not accidentally erase dynamic content, which is a possibility if not handled correctly.
